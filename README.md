# Disk-Audit
This script scans the Vms running with premium OD and Data Disk and list Them

Open the Azure cloud shell then do the following:-

1. **Create the Script File**
   
    nano list-premiumssd-vms.sh
	
3. **Copy the entire code given in the file**

4. **Save and Exit**
   
 CTRL + O (To Save the file)

  Enter

 CTRL + X (To Exit the script)

4. **Make script Executable**
   
chmod +x list-premiumssd-vms.sh

6. **Run the Script**
   
./list-premiumssd-vms.sh
